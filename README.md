Microservicios con Spring Cloud

🔗 https://github.com/YuukoI/MicroservicesWithSpringCloud

Tecnologías: Java · Spring Boot · Microservicios  · Spring Data JPA · Hibernate · MySQL · Spring Cloud · OpenFeign · Eureka Server/Client · LoadBalancer · API Gateway · Resilience4j · Maven · Git/GitHub  · Zipkin/Brave.

Implementación de una arquitectura de microservicios utilizando el ecosistema de Spring Cloud, explorando conceptos avanzados como balanceo de carga, comunicación entre servicios y resiliencia. El proyecto integra distintos módulos independientes con descubrimiento de servicios, seguridad y un API Gateway centralizado, asegurando escalabilidad y tolerancia a fallos.

Rol:

- Diseño e implementación de microservicios con Spring Boot y Spring Cloud.
- Configuración de Eureka Server/Client para descubrimiento y registro de servicios.
- Integración de comunicación entre microservicios con OpenFeign.
- Implementación de Load Balancer y manejo de tolerancia a fallos con Resilience4j.
- Desarrollo de la capa de persistencia con Spring Data JPA, Hibernate y MySQL.
- Exposición de servicios mediante API Gateway.
- Gestión del proyecto con Maven y control de versiones en Git/GitHub.
- Implementación de trazabilidad distribuida con Zipkin y Brave.
